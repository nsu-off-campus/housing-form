# Off-Campus Housing Unit Condition & Exit Survey

Mobile web form for Dr. Pallavi Patel School of Health Sciences off-campus student housing.
Students complete a move-in condition report or a move-out check-out and exit survey, then email
the report and photos to realestateleases@nova.edu and odoo@nova.edu.

Live form: https://nsu-off-campus.github.io/housing-form/
